# Reusable interface components

- `building` Clinical interface framework: a CSS and component framework that gives new or existing clinical applications an interface already tested for clinical safety, usability and accessibility: a "Twitter Bootstrap of Medicine". The [NHS design system](https://github.com/nhsuk/nhsuk-frontend) shows how this works for public-facing websites, and NHS England has [decided to extend it with staff-facing components](https://digital.nhs.uk/blog/design-matters/2026/one-design-system-is-better-than-2) rather than build a separate clinical design system. The older NHS Common User Interface was withdrawn in 2019, and has since been [rescued into Markdown](https://github.com/pacharanero/nhs-cui). Open project: [Common User Interface](https://github.com/giussepe198/common-user-interface), started by Gabe Rijpma in October 2026, turns the CUI guidance into about 180 React and TypeScript controls under the Apache 2.0 licence, extended for Australia and New Zealand, with each control citing the guideline it implements. It describes itself as a design and engineering reference, not a certified medical device.
- `building` Embeddable SNOMED CT code picker: an open, accessible picker backed by a terminology server, so applications stop building their own. The [Common User Interface](https://github.com/giussepe198/common-user-interface) project has a `TerminologySearch` control for coding a single SNOMED CT concept. The application supplies the search function, so it still needs pairing with a terminology server such as [hermes](https://github.com/wardle/hermes).
- `building` Embeddable early warning score components: NEWS2, PEWS and maternity early warning scores as open, tested components. [Digital PEWS](https://github.com/ohtf/digital-pews), an OHTF Foundation Project, covers the national paediatric chart. The [Common User Interface](https://github.com/giussepe198/common-user-interface) project has early warning score and observation chart controls with NEWS2, Australian ADDS and New Zealand NZEWS presets. The maternity score has no open equivalent.
- `missing` Interactive anatomical diagrams with terminology bindings: body and anatomy diagrams that clinical systems can embed, where clicking a structure selects its SNOMED CT body structure code (or the equivalent in another terminology).
- `partial` Family trees in a text format: clinical pedigrees and genograms written as text and rendered as diagrams. [SchemaTex](https://github.com/SchemaTex/SchemaTex) is an open-source text format for pedigrees and genograms. There is no agreed clinical standard and no EPR integration yet.
- `missing` Open clinical photography capture: an open capture component that records consent and metadata and saves images to the EPR as DICOM or FHIR, following [Institute of Medical Illustrators guidance](https://www.imi.org.uk/wp-content/uploads/2019/10/NG_Mobile_Devices_2_0.pdf).
